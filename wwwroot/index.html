印刷标准知识库

CMYK 数值必须依附于具体印刷条件才有意义。下列数据依据 ISO 12647-2、FOGRA 39/47/51、ECI、 IDEAlliance GRACoL 等公开标准整理，用于总墨量校验与实地色参考。

怎么判断该用哪个标准？

CMYK 没有绝对值。同一个 C0 M80 Y60 K0 印在铜版纸上和在新闻纸上完全不同， 因为纸张吸墨能力与印刷方式决定了能承载多少墨、能达到什么色域。 标准 = 纸张类型 × 印刷工艺 × 地区惯例，三者共同确定。

1
先问印什么纸
  • 铜版纸 / 涂布纸（画册、包装盒）→ PSO Coated v3、ISO Coated v2
  • 非涂布纸 / 胶版纸（说明书、报纸）→ PSO Uncoated、FOGRA39
  • 不确定 → 问印刷厂要 ICC 配置
2
再问什么工艺
  • 单张纸胶印（画册、名片）→ 限墨可到 330%
  • 轮转胶印 / 商业轮转（报纸、期刊）→ 限墨 260~300%
  • 数码印刷（短单、个性化）→ CGATS TR 001
3
最后看地区惯例
  • 欧洲 → ISO Coated / PSO 系列，ECI 发布
  • 北美 → GRACoL、SWOP，IDEAlliance 发布
  • 日本 → Japan Color
✓
权威做法
  • 直接向印刷厂索取 PDF/X-4 与其 ICC 配置，按它为准
  • 不确定时用 PSO Coated v3（现行国际默认，限墨 300%）
  • 本工具的 CMYK 是按标准特性的模型换算值，非 ICC 软打样结果
